# Transferable CLI

Upload files and create deliveries on [Transferable](https://transferable.io) from the
terminal, or let your AI agent do it.

```sh
npm install -g @transferable/cli
transferable login
transferable upload ./Wedding-Dupont --folder "Dupont"
transferable deliver "Wedding - Dupont" --from "Dupont" --publish
```

Also available with `brew install transferable-io/tap/transferable` or
`curl -fsSL https://transferable.io/install | sh`. More on
[github.com/transferable-io/cli](https://github.com/transferable-io/cli).
